# Assets Directory

Este diretório armazena recursos visuais, diagramas de arquitetura, capturas de tela e badges utilizados na documentação do repositório e de seus subprojetos.

## Estrutura Recomendada
- `/assets/diagrams/`: Diagramas de fluxo e arquitetura do software.
- `/assets/screenshots/`: Demonstrações visuais das interfaces CLI e relatórios gerados.
