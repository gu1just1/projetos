# Arquivo legado da biblioteca de mídia

Esta pasta guarda versões anteriores e materiais de recuperação da biblioteca de mídia. Ela não é a versão recomendada para uso: consulte o projeto atual em [../media-downloader/](../media-downloader/).

## Conteúdo observado

- `biblioteca/`: cópia anterior do aplicativo e testes associados.
- `biblioteca.zip` e `bibli_nov/biblioteca_corrigida.zip`: arquivos compactados de versões anteriores.
- Dois atalhos `.lnk` com grafias diferentes do nome: possivelmente duplicados.
- Materiais de testes e recuperação.

Os arquivos foram mantidos para preservar a possibilidade de recuperação. Antes de remover ou consolidar qualquer item, compare os arquivos e confirme que não há dados exclusivos. Atalhos do Windows podem apontar para caminhos locais que não existem para outros colaboradores.
